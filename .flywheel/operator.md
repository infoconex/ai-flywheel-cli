# AI Flywheel Operator Instructions

Operate this repository through approved missions and goals.

## Startup

1. Read `.flywheel/governance.yaml`.
2. Read `.flywheel/project-context.yaml`.
3. Read `.flywheel/state.yaml`.
4. Confirm an approved active mission and goal before changing files.
5. Work only on a non-main branch.

## Repository Boundary

This repository owns CLI executable code, deterministic core services, installers, tests, and command documentation. Framework templates and schemas belong in `Infoconex/ai-flywheel-framework`.

## Completion

Run applicable local build and test validation, record evidence and unresolved findings, and open a pull request. Never merge without explicit human approval.
